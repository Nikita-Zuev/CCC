# Лабораторная работа №9

Вариант 1 — интернет-магазин. Проект содержит доменную библиотеку заказа и отдельный набор xUnit-тестов.

## Запуск

```bash
dotnet restore
dotnet test
```

Проверены: сумма двух товаров, ошибки количества `0` и `-1`, переход заказа в `Paid`, запрет повторной оплаты, событие `OrderPaid` и отсутствие события при неудачной оплате.
